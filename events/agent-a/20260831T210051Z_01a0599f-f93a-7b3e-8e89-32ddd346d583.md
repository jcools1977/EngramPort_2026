# Handoff: the published SDK's `handoff()` writes nothing

**Found by hard-testing `@engramport/sdk@0.1.0` from a clean `npm install`, one hour after publication.** Recorded as F135.

**`handoff()` returns a success object with a plausible `relative` path and no file is written** — not at that path, not anywhere on the filesystem. `append()` in the identical fixture writes correctly, so it is specific to the handoff path rather than to `cwd`, configuration, or the actor record. Reproduced in an isolated project with only alice and bob registered.

**The failure is silent, which is the serious part.** A caller receives success and has no reason to check. **A consumer would believe responsibility had been transferred while nothing was recorded.**

## Why every control missed it

The SDK suite, the clean-install control from F133, and all 155 mutation controls pass. **They exercise the core through the CLI and through the wrapper's own append path. Nothing exercises `handoff()` through the published surface.**

**F133's control proves the package installs and imports. It does not prove its methods work.** That distinction is the finding underneath the finding.

## Deliver

**Fix `handoff()`**, and determine whether `complete()` and `createPortWatch()` share the defect — `reply()` at least fails loudly, refusing without `inReplyTo`.

**Then close the gap that let it ship:** a control that exercises **every exported SDK method against a clean install of the packed tarball**, asserting for each that the promised artifact exists on disk afterward. **Returning a path is not evidence a file was written**, and that is precisely the assumption that failed here.

**Publish 0.1.1 only after that control passes.** Do not remove 0.1.0; leave it and let the fixed version supersede it.

## Evidence

- Each exported method, called against a clean install, produces the artifact it reports.
- A discriminating mutation: break one method's write and show the new control fails while the existing in-repository suites still pass. **That contrast is the whole point.**
- The repository's own log verifies unchanged.

**Bounds.** The SDK, its published-surface control, and its mutation. No protocol or envelope change, no site copy change, **no npm publish** — DeVere publishes, and he is away until morning. `executed=` moves from its observed value, which you state.
