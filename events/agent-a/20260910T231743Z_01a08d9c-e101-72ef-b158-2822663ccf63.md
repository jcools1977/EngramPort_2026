# Handoff: `version.subject` names a committed blob or says it came from a working tree; free text is refused

ADR 0054 was amended today with the rule Nick's agent added on council 07: a subject is identified by the hash of the committed blob, never by a path, and a result whose subject was read from a working tree says so. Read the amendment at the end of `docs/adr/0054-environment-on-the-claim.md`. This lands before 0.5.0 is published, so the schema can still change.

## Objective

1. `schemas/event-v2.schema.json`: `version.subject` is `null` or a string matching `^blob:[0-9a-f]{40}$` or `^worktree:[^\s]{1,200}$`. Document both forms in `PROTOCOL.md` next to the existing v2 environment paragraph: `blob:` is the git blob sha of the committed bytes the result speaks about; `worktree:` is a relative path under the repository root and means the bytes were read from a working tree and are not fixed by the claim.
2. `verify-log.mjs`: the V2 environment check refuses any other form with its own marker (`V2_ENV_SUBJECT`), and the CLI passes the reason through unchanged.
3. Controls: a v2 completion with `subject: "blob:<40 hex>"` appends and verifies; `subject: "worktree:packages/sdk/src/cli.mjs"` appends and verifies; `subject: "packages/sdk/src/cli.mjs"` (a bare path) and `subject: "0.5.0"` are refused at append with the marker in the reason; `null` still passes. Mutation: with the verifier check removed the bare path appends, shown then restored.
4. Update the one place our own completions build the environment object (the agent-b completion path or its documentation in AGENTS.md) so builders know to write `blob:` from `git rev-parse HEAD:<path>` and `worktree:` otherwise.

## Bounds

`schemas/event-v2.schema.json`, `packages/git-adapter/src/verify-log.mjs` and its tests, `PROTOCOL.md`, `AGENTS.md`, the 0.5.0 changelog entry. Existing v2 events in this log must still verify: run `npm run proof:verify` and quote it; if any existing v2 event carries a free-text subject, stop and report which, since history is not rewritten. Commit nothing; the dispatcher commits.
