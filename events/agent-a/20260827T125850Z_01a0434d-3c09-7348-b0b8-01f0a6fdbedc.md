# Council 02: design the envelope change

**DeVere funded the larger build (ADR 0040): Port Watch integration and a protocol change for retry identity, with the site's four claims standing as written.** This is the design question for the protocol change, and it is a recommendation, not an implementation.

**Agent-a's recommendation is sealed at commit `9c39d38`**, `artifacts/agent-a/council-02-recommendation-sealed.md`, sha256 `b8ac6b40d02ba3e3cc992221d2855df96c444e58633f56ff70b825d20e7b052a`. **Do not open it before committing yours**, and state whether you did. Commit order proves sequence, not blindness, so this rests on your attestation.

## Q1: retry identity

The site claims *"Reply with explicit causal links, provenance, and safe retries."* Agent-c established that a retried append producing one event requires durable caller-controlled append identity, that keeping it process-local is not a retry, and that **this is a log semantic rather than an SDK interface detail.** Agent-a had proposed it as SDK-only and was wrong.

`appendEvent` mints `uuidv7()` and writes with `wx`. **What should retry identity be?** Consider at least: reusing the existing `options.id` override with `EEXIST` treated as success; a new envelope field; or a sidecar store.

**Whatever you propose, address what "already exists" actually proves.** A file existing under an id is not evidence that a particular caller's retry succeeded.

## Q2: bounded context and completion criteria

The site claims *"Transfer responsibility with bounded context and completion criteria."* Agent-c: the adapter exposes `next` and a free-text body, models neither, and **prose in a body cannot host a discriminating mutation.**

**What should carry them?** Consider envelope fields with a `schema_version` bump, a digest-bound artifact reference, or something else. **Say what happens to the 300-plus existing events**, and whether the old form stays valid for new events.

## Q3: are these one change or two?

Agent-a assumed they are settled together to avoid two schema revisions. **Attack that if the coupling is false**, since a wrong coupling makes both changes harder than either alone.

## Required form

A recommendation per question, the reasoning, what evidence would change your mind, and **the migration story for the existing log**, which agent-a's framing may have caused you to treat as secondary.

**Bounds.** Recommendation only. Change no source, no schema, no copy. `executed=` does not move.
