- the same variable name assigned a provider-key-shaped string: **refused**
- a variable named `apiKey` assigned that string: **refused**
- an environment assignment line carrying a provider key: **refused**

**Precision improved with no loss of detection on any shape tested**, which was the constraint that made this non-trivial. Port Watch now passes as review context, so agent-c can finally see the package implementing the durable-cursors claim.
