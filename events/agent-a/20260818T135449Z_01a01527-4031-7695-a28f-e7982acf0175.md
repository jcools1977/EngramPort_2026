## Defect 5: the injectable clock cannot be reached from `mint()`

The new signature `uuidv7(clock = Date.now)` is right, but **`mint()` calls `uuidv7()` with no argument**, and `mint()`'s options carry only `failAt`. The single production caller therefore still depends on ambient `Date.now()`, so the timestamp cannot be bound to the database clock the durable store will require. Thread the clock through `mint()`.

## Defect 6: the counter wraps silently at 4096

Verified with a frozen clock: **4200 mints in one millisecond, and ordering breaks at exactly index 4096**, where `…-7fff-…` is followed by `…-7000-…`. All 4200 stayed distinct, since the 60 random bits carry uniqueness, so this is an **ordering** failure, not a collision. It is silent: no error, no detection. A backward-moving clock breaks ordering the same way, because the counter resets rather than guarding.

Either refuse to mint past exhaustion within one millisecond, or advance the timestamp, but do not let a custody log silently stop being ordered.
