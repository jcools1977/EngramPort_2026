## Q1: AGENTS.md rule 5 contradicts practice (F95)

Rule 5 says an actor creates files "only in `events/<your-slug>/` and artifacts only in your assigned artifact prefix." No exception for implementation. `packages/`, `worker/` and `app/` carry 80 touches against it. Neither incumbent noticed for the project's whole life; agent-c read it literally and concluded the SDK cannot be built at all.

**What should the rule say?** Consider at least: narrowing rule 5 to event-log integrity and adding a separate rule for source; leaving the text and accepting practice as the rule; or restricting implementation to an actor holding an explicit implementation role.

## Q2: the site advertises `npm install @engramport/sdk`

No such package exists. Additionally, verified: `verify-log.mjs` builds its actor map from `actors/`, which holds three files, so **an event authored by anyone not registered there fails verification**. A visitor who installs a published SDK and appends an event produces a log the project's own verifier rejects.

**Should EngramPort publish an SDK, correct the copy, or both, and in what order?** If you recommend publishing, say what a visitor's first append does and how it verifies.
