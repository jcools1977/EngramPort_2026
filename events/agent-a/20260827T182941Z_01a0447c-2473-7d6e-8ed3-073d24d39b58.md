# Handoff: make agent-c run without agent-a

**DeVere asked whether everything is automated. For agent-c it is not, and never has been.** Its poller is not scheduled in launchd or cron, and the supervisor reads `XAI_API_KEY` from the environment, so **all eleven Grok reviews this session happened because agent-a typed the command with DeVere's 1Password credential.** When `op` timed out twice today, agent-c ceased to exist and agent-a accepted three deliveries unreviewed as a direct result.

This is also the product defect in miniature. ADR 0039 defines EngramPort as builders running **their own agents on their own tokens**; ours is a subprocess of agent-a's session.

## The constraint that makes this non-trivial, and which you should solve rather than route around

**A scheduled job cannot complete an interactive 1Password unlock.** The standing rule is no secrets on disk: connection strings, keys and tokens are supplied at the moment of use and never written into the repository, the scratchpad, or any tracked or untracked file.

**Do not resolve this by writing a key anywhere.** Assess at least: a 1Password service account whose token lives in the macOS Keychain rather than a file; `op` daemon or Connect; or keeping invocation manual while automating only the trigger. **Say which you chose, what it does not cover, and whether it widens the credential's blast radius**, since this machine holds every key in the estate.

If your honest conclusion is that no option satisfies the constraint, **say so and recommend the least-bad arrangement with its exposure stated.** A half-automated agent whose limits are documented beats an automated one whose credential path nobody examined.

## Deliver

- **The poller scheduled** so agent-c discovers its own turn, on the same capability boundary as the relay notifier: inspect, log, notify.
- **A credential path that does not route through agent-a's session**, per above.
- **A refusal that is loud when the credential is unavailable.** Today the failure mode is silence, and silence is indistinguishable from "no work pending", which is how three deliveries went unreviewed.

## Evidence

The negative control matters most: **prove the scheduled poller stays silent when agent-c has no actionable turn**, and prove it reports rather than fails quietly when the credential cannot be resolved. A discriminating mutation for each. **Do not run a live model call in tests.**

**Bounds.** Scheduling, credential path, failure reporting. No change to the review schema, no protocol change, no SDK, no reporter. `executed=` moves from **127**.
