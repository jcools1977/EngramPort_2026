# Objective: implement the Durable Object transaction store, wired to a real route

DeVere chose **shape A** from your costing. ADR 0032, digest `c085559f8e61bea26c08a4806217591be47b10f7f7a4e553468460b27a848582`.

**Your costing decided this, and two of its findings are now binding rules** rather than observations: deletion is not erasure because of the 30-day PITR tail, and ADR 0031 is **amended** for Workers rather than reinterpreted.

**One thing your reading unlocked that is worth stating**: because a Durable Object is keyed by the `state` already in the callback query, **no cookie carries continuity, so the host-sharing trap you identified does not apply.** The production redirect URI is consequently decided: `https://app.engramport.com/auth/callback`.

## Dispatched

Your own surface list from the costing, treated as the specification:

1. **An asynchronous transaction-store seam** replacing the synchronous `Map` at `oidc-client.mjs:21-40`, **preserving generate-before-redirect, exact expiry, and consume-before-exchange**.
2. **The Durable Object class**, keyed by `state`, that **persists `{state, nonce, codeVerifier, redirectUri, expiresAt, status}` to storage before the authorization redirect returns.** Keeping it in object memory reproduces the defect this decision exists to fix — you said so, and it is the requirement most likely to be quietly skipped.
3. **Atomic claim-or-delete before token exchange**, failing closed on interruption. A claim committed before an interruption loses that authorization; that is the accepted disposition and the founder restarts.
4. **Expiry authoritative on every read**, including against a row that could have been restored from PITR. **Alarm-based cleanup, and `deleteAll()` so an emptied object retains no metadata.**
5. **Wiring in `vite.config.ts` and `worker/index.ts`** so the store has a **real caller** — namespace, class binding, migration and required secret names declared in **source configuration, not the ignored generated `dist/server/wrangler.json`.**

**Item 5 is not optional.** F76 and F77 both landed on the same defect: a module with no caller is green tests against an unused engine. **Do not deliver items 1 to 4 alone.**

## Evidence, with the distinction you drew

Local Wrangler or Miniflare controls proving same-name object routing, **survival across an induced isolate restart**, atomic competing callbacks, expiry refusal, cleanup, and **neither verifier nor nonce appearing in any response or log**. Paired positive and a discriminating mutation each.

**Every claim must state what the local run proves and what it only simulates.** Local emulation cannot establish global request distribution, production placement, control-plane access, PITR retention or platform availability. **A local green run is not production isolate evidence**, and asserting otherwise would be the fake-scheduler pattern wearing a different hat.
