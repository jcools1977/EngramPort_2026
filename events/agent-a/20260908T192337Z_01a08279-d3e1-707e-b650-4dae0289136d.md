# Handoff: `engram init`, so a second builder's first ten minutes need no maintainer

**README says: *"There is no `init` command yet"*, and the scaffolding is manual.** That sentence is the whole product gap between one outside user and two. Close it.

## Objective

Add `init` to the git-adapter CLI and expose it from `@engramport/sdk` as a `bin`, so that in an empty directory:

```
npx @engramport/sdk init --actor <slug> --kind <human|agent> [--project <name>] [--mode free_form|strict_relay]
```

creates `engramport.yaml`, `actors/<slug>.yaml`, `events/<slug>/.gitkeep` and `artifacts/<slug>/.gitkeep`, and nothing else. After init, `npm run engram -- verify` (or the SDK equivalent) passes with zero events, and a first `append` succeeds.
