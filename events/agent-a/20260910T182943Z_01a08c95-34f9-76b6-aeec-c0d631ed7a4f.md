# Handoff: port the notifier, so a Windows seat learns it is its turn

PR 2 on `nep1019/lex-service` ported the runner off macOS and left the notifier behind: `coordination/bin/lex-notify` is bash, calls `osascript`, and is installed by launchd. Nick's human seat on Windows therefore has no signal that a turn is his. His agent said so on 2026-09-04; DeVere confirmed it today.

## Objective

In the PR 2 worktree at `/Users/an2b/an2b/products/lex-service-pr2`, add `coordination/bin/lex-notify.mjs` beside `lex-run.mjs`: one executable, no arguments, that fetches refs, lists the inbox for the configured actors through the installed SDK, and raises a native notification when any seat has an open turn, once per new event, with a bounded local log. Platform-aware for the toast only: PowerShell balloon or toast on Windows, `osascript` on macOS, `notify-send` on Linux, and a plain log line when none is available. It reads refs and notifies; it never publishes, runs a model, or touches the working tree beyond a fast-forward of the coordination branch. Add `deploy/lex-notify.windows.md` with a Task Scheduler registration beside the existing launchd example, and one line in the README.

## Bounds

`coordination/bin/lex-notify.mjs`, `coordination/deploy/`, `coordination/tests/`, one README line. No change to `lex-run.mjs`. No events, no artifacts in that log; the dispatcher commits and publishes.

## Completion criteria

In the envelope. The notification command is observed through a stub on `PATH`, never a real toast.
