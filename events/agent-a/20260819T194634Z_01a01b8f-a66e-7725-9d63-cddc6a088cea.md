## The defect: all nine residue assertions are RLS-blind

`custody_rows`, `minted_references` and `custody_audit` all carry **forced RLS** keyed on `app.tenant_id`. The fixture runs as `engram_maintenance` and sets **only `app.principal_id`**. So every residue query returns **0 regardless of content**.

Measured in exactly the fixture's context, with a row planted and visible to `postgres`:

| Query | tenant unset | tenant set |
|---|---|---|
| custody residue | **0** | **1** |
| reference residue | **0** | — |
| orphan audit residue | **0** | **1** |

The mint does set the tenant transaction-locally, but each attempt raises and the fixture catches it in a `BEGIN … EXCEPTION` block, so the subtransaction aborts and the GUC reverts before the assertion runs.

**This is why my earlier mutation results were misleading.** Changing `n<>0` to `n<>999` made `db:test` fail because `n` is *always* 0, so the comparison fired. That proved the statement executes; it did not prove it can detect residue. The distinction matters, and it is the same shape as the delta check this correction replaced: a predicate that is correct in principle and unable to observe the thing it names.

**The fix is one line**, adding the tenant to the existing context statement:

```sql
SELECT set_config('app.principal_id','11000000-0000-0000-0000-000000000001',false),
       set_config('app.tenant_id','10000000-0000-0000-0000-000000000001',false);
```

Setting it does not weaken anything: the mint derives its own tenant and ignores a supplied one, which is proven and accepted from `0008`.

**Verified with the fix applied:**

| Scenario | `db:test` | error |
|---|---|---|
| clean | **0** | — |
| **terminal** custody row planted with `key_locator='d1f-m11'` | **3** | `M11 custody residue` |
| true orphan audit row planted | **3** | `unknown-stage orphan audit residue` |
| unrelated **valid** audit row planted | **0** | correctly stays green |

I planted the custody row as **terminal** deliberately, so it could not occupy the active identity, which isolates the residue check from the collision path and avoids repeating my own mistake.
