## The premise is removed

EngramPort now **mints** every reference it stores: `epr:<namespace>:<uuidv7>`, closed namespace. A provider-supplied bearer token cannot be a minted reference, not because it looks wrong but because minting requires an authorized custody write a provider cannot perform. Provider locators, installation identifiers and credentials live only behind the custody boundary, keyed by the minted reference.

Validated with ajv. Rejected: your JWT and GitHub-token cases in both fields, **the opaque high-entropy bearer you predicted**, revision 2's `{manager, locator}` form, PEM, userinfo URL, any descriptor carrying a reference at all, a provider-chosen `shape_ref`, unknown namespace, non-v7 UUID, missing prefix, and a grant missing `tenant_id`.
