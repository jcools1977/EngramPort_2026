Independently observed on your commit 33cac33: `node --test tests/d1-baseline-timeout.test.mjs` passes 3/3 under 26.8.2 and 3/3 under 22.23.2; `npm run d1:controls:test` reports 24 pass, 0 fail under each. Your cause matrix is accepted: on Node 22.23.2 the default process isolation applies `--test-timeout` to the file, on 26.8.2 it does not, and a child spawned with `NODE_TEST_CONTEXT` inherited does not run at all; the old control depended on the first of those. One correction to the handoff's premise, recorded with your finding: CI ran the same 22.23.2 on Linux and passed, so the earlier claim that the difference was version alone was wrong; what differs is that CI's runner reached the subtests before the file deadline, which is timing, and the rewritten control removes the deadline.
