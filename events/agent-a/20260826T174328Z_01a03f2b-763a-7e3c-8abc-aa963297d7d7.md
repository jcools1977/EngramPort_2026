# Handoff: split rule 5, and make the divergence impossible to reintroduce

**DeVere approved this, recorded as ADR 0038.** It was class 3 under ADR 0028 and could not be dispatched on the council's unanimity alone.

**Amend AGENTS.md** so that rule 5 governs only what it is actually for, using the shape both voters converged on:

- **Event and artifact ownership keeps append-only, actor-owned enforcement.** An actor creates accepted events only through `npm run engram -- append`, landing in its registered event directory, and never edits an accepted event or another actor's files. This is the audit trail and the strong property is the point.
- **Source, tests, documentation, configuration and migrations are editable by any actor**, arriving through the relay with paired evidence and a discriminating mutation.

**The text is the small half. The control is the deliverable.**

F95 existed because the written rule and the practice disagreed for the project's entire life and **neither incumbent noticed, because both read the practice as the rule.** Rewriting the text fixes today's contradiction and does nothing to stop the next one.

**Deliver a control that fails when a tracked path is not permitted by the rules as written.** Concretely: derive the permitted surfaces from `actors/` records and the new source rule, enumerate tracked files, and fail naming any file the rules do not account for. **The test of whether it works is that it would have failed before this amendment**, on the 82 implementation touches. Report whether it does; if it would not have, the control is decorative and say so plainly rather than adjusting the claim.

**Required evidence.** A discriminating mutation that reverts the amendment and shows the control then rejects the repository's own source tree. The 330 events verify unchanged. `npm test` passes.

**One thing to check rather than assume:** whether this amendment makes anything currently forbidden newly permitted that should not be. **Rule 5's real security work is preventing an actor from forging or editing another's events**, and if any part of that protection was resting on the broad wording rather than on the ownership rule, splitting the text would quietly remove it. Say so if you find it; that finding outranks the amendment.

**Bounds.** AGENTS.md and the new control only. No SDK, no enrollment path, no protocol change, no change to `actors/` records or migrations. `executed=` moves from **116**.
