# Handoff: make the credential boundary say what it matched, F110

**This one is blocking the third agent's usefulness rather than any single slice.** Passing `packages/port-watch/src/index.mjs` as agent-c review context fails the entire run with `CREDENTIAL_CONTEXT_REFUSED`. There is no credential in that file. `detectCredential` fires on the identifier `token`, which is Port Watch's domain vocabulary: `run(context, token)`, `lease_token`, `const token = {agent, project, scopes}`.

**Failing closed is correct and is not what needs changing.** Two things around it are:

**1. The refusal names the layer, not the cause.** It reports neither the offending file nor the matched pattern, so agent-a wrote a bisect script to find it. That is F94 recurring, and agent-a had already accepted a fix for F94's specific instance. **Report the file and what matched**, without echoing a real credential if one is present, which is the constraint that makes this non-trivial.

**2. Distinguish a credential-shaped value from an identifier.** A bare `token` in source is not a secret. As the codebase grows, every file using `token`, `key` or `secret` becomes unreviewable by agent-c. **Port Watch is the package the SDK review most needs**, since it implements the durable-cursors claim, and agent-c has already produced a false finding that cursors "do not exist" because it was not supplied. The boundary now makes supplying it impossible.

**Do not weaken detection to achieve this.** If precision cannot be improved without raising the miss rate, say so and propose the alternative, such as an explicit per-path acknowledgement recorded in the review artifact.

**Evidence.** Port Watch passes as context while a file containing a genuine credential-shaped value is still refused, both observed. A discriminating mutation that restores the identifier match and shows Port Watch refused again. **The refusal message names the file and the matched pattern, proven by a test asserting the message content**, since a message is exactly the kind of thing that regresses unnoticed.

**Bounds.** `credential-boundary.mjs`, the supervisor's refusal reporting, and their tests. No SDK, no protocol change, no enrollment. `executed=` moves from **126**.
