The seven not-exercised are the Node 26 Miniflare startup abort, recorded before and expected here; the counts reconcile. The one failure is new to this branch. On the previous three full runs of the pre-fix harness that mutant read `forbidden=t`.

## What changed its shape

The mutant still fails the test (`after=1`), but for the wrong reason. The canary log shows the run dying at `validateEvidenceRecord` with `CREDENTIAL_INPUT_REFUSED at $.evidence` inside `engram-canary-*/vulnerable-modules/packages/git-adapter/src/report-boundary.mjs?canary=...`, instead of reaching the point that prints `W1_7_REPORT_INCIDENT excluded=true recorded=false landing=event-file count=0`.

`make_canary_variant` copies the whole of `packages/git-adapter/src`, `packages/port-watch/src` and `schemas/` into the variant root, and the canary test then copies that root again into its own temp tree and imports with a cache-busting query. Your sweep replaced the five `fs.writeFileSync` calls in that builder with `writeVariant`, which rewrites `./credential-boundary.mjs` and `../../port-watch/src/index.mjs` in the mutated file to absolute `file://` URLs under the first copy. The mutated module then loads its dependencies from the first copy while the test loads everything else from the second, so the graph is split across two trees and two module instances. The rewrite exists for detached single-file variants; a whole-tree copy already resolves correctly and must not be rewritten.

## Objective

1. In `make_canary_variant`, write mutated files without import rewriting. Either call `fs.writeFileSync` there with a one-line comment saying why this builder is exempt, or give `writeVariant` an explicit no-rewrite form; do not special-case by path string.
2. Audit every other builder you switched to `writeVariant` for the same shape: any variant that is a directory copy the test resolves on its own. List each builder with its verdict (detached file, or whole-tree copy) in the results artifact.
3. Extend the drift control so this class cannot come back: a test that, for a whole-tree copy builder, asserts the mutated file still contains only relative specifiers, and that fails when the rewrite is applied to it (run it against the d0a40a1 form and show the failure).
4. Run the live gate to completion: `npm run db:test` in this worktree with the bundle built, and quote the `D3_CANARY_REPORT_INCIDENT` line, the summary line, and the exit. Node 26 not-exercised lines are expected and must still be exactly the seven Miniflare ones.
