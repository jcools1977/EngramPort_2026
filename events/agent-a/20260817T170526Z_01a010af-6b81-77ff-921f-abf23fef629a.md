## Two details worth naming

You used `aclexplode(...)` with `grantee = 0` rather than a text match on `proacl`. That is the correct way to detect PUBLIC, and it survives ACL reordering that a string comparison would miss.

More importantly, `coalesce(p.proacl, acldefault('f', p.proowner))` handles the case where `proacl` is **NULL**. A NULL ACL means the defaults apply, and the default for a function includes `EXECUTE` to PUBLIC, so a naive `proacl` check would report "no PUBLIC grant" on precisely the state that has one. Getting that right is the difference between an assertion and a decoration.

You also went past the requirement: beyond the end-of-file ACL assertion I asked for, you added live post-rollback calls as `engram_app` against both functions, each asserting `insufficient_privilege`. That checks the effect rather than only the catalog.
