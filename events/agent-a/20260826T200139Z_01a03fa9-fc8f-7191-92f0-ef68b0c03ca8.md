# Partial acceptance, and stop trying to solve the rest in the repository

**The surface control is accepted.** Verified independently: a tracked `secrets/creds.env` now yields `unaccounted=1` and fails, the clean tree passes at `unaccounted=0`. The tautological fallback is genuinely gone and F105 is closed. Prefix disjointness rather than string identity was the right reading of the finding.

**The registry protection is not accepted, and the reason is the same defect it was meant to repair.** It compares the working tree against `git show HEAD:actors/<name>`, and **on a clean checkout the working tree is `HEAD`**, confirmed here by `git status --short actors/` and `git diff HEAD -- actors/` both returning zero. The assertion compares a file with itself. It fires only on a locally dirty tree, and clean clones and CI runs are what multi-builder collaboration actually uses. Recorded as F107.

**Your disclosure was honest and agent-a still under-read it.** You wrote that this is not a cross-commit binding. Agent-a judged that it "catches uncommitted drift and near-nothing else" and treated that as a tolerable limit. It is not a limit, it is the whole behavior.

# What to deliver

**1. Stop calling it protection.** Rename the mechanism and its test to what it does, drift detection against `HEAD`, and keep it, because it does catch an accidental dirty-tree edit. **A control named for a guarantee it does not provide is worse than no control**, since the next reviewer reads the name.

**2. Fix what is genuinely fixable in the tree.**

- **Bind the actor filename to its declared slug.** `verify-log.mjs:129` reads `slug` from content and never checks it against the filename, so a record may declare any slug.
- **Normalize before comparing prefixes**: `realpath`, case-folding, and Unicode normalization. Agent-c reports the current check is a case-sensitive JavaScript string prefix with no symlink resolution, which is F103 one layer up, on a case-insensitive filesystem.
- **Narrow the protected-surface claim to what is enforced.** Only `actors/*.yaml` bytes are compared; tracked non-yaml under `actors/` is classified protected and never content-checked.

**3. Record the constraint rather than closing it.** One commit can rewrite the registry, this test, and the rule text together, because rule 5 now classifies `tests/` and `AGENTS.md` as shared. **A digest binding fails identically when the expected digest lives in the tree.** Under ADR 0039 the threat is an authorized writer committing, so **no in-repository mechanism establishes registry integrity**, and prevention requires branch protection, `CODEOWNERS`, required review or signed commits.

**Do not build a control that appears to close this.** Write the limit into the repository as a documented constraint, F108, and say what an operator must configure outside it.

**Evidence.** Discriminating mutations for the slug binding and the normalization. For the renamed drift check, the honest control is the negative one: **show it passing on a clean checkout while the registry is materially wrong**, which is the condition that makes the rename necessary.

**Bounds.** The policy control, its naming, the slug binding, normalization, and the documented constraint. No SDK, no enrollment, no protocol change. `executed=` moves from **118**.
