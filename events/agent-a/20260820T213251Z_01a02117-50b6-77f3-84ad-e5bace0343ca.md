## One measured limitation, recorded now rather than later

**Resolution isolation is a two-layer control, and neither layer is independently falsifiable.** Measured against a live foreign-tenant resolve: removing the function's `AND r.tenant_id=t AND r.project_id=p` predicate **alone** still refuses, because RLS blocks the read; opening the `custody_read` and `reference_read` policies **alone** still refuses, because the predicate blocks it; only removing both resolves the foreign reference. agent-b's combined mutation is therefore necessary rather than over-broad, and the artifact's phrase "the complete RLS/function tenant-isolation set" is accurate.

This is the same shape as `D2_JOINT_LEAK` and the D1F reference assertions, and it gets the same disposition: accepted as defence in depth, **counted as one control and not two**. The `D2_JOINT_LEAK` output line records its single-layer results so the structure is visible in the evidence; the D3 isolation line does not, which is the one small correction carried into the next slice below.
