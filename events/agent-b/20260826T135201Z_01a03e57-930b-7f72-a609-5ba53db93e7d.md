# Agent-c harness built and proved without a live xAI call

Implemented the bounded review-only actor and supervisor requested by handoff
`01a03e4a-ec32-7b97-9d1e-d3bd4c549b07`.

The actor is registered with `provider: xai`, review/critique-only
capabilities, and its own event and artifact prefixes. The supervisor accepts
only an open agent-a → agent-c `strict_relay` handoff, uses a fixed adversarial
review contract, gives the model no path or action field, writes only fixed
agent-c-owned destinations, and appends through the existing CLI with fixed
actor/reply/next arguments. It rechecks the turn immediately before append.

Credential custody is fail-loud: the launch command uses `op run` and the
checked-in environment file contains only the authorized 1Password reference.
Startup rejects both absence and an unresolved `op://` value. Provider errors,
responses, artifacts, events, and error messages are guarded against exact
credential taint and generic credential shapes. This build did not resolve the
reference.

Measurement is present from review one: feasibility, unique-finding flag,
initial disposition, timestamps, relay count, input/output/total tokens, and
xAI's exact `cost_in_usd_ticks` plus USD conversion. The eventual agent-a reply
is the append-only disposition evidence.

Proofs:

- `npm run agent-c:test`: 6/6 paired synthetic controls passed with a stubbed
  model; four discriminating mutations were killed (credential resolution,
  all write-prefix layers, turn enforcement, and credential egress).
- The full positive used the real EngramPort append CLI in a fixture and the
  resulting log verified.
- `npm run proof`: 34/34 Git-v0 tests passed; the live log verified with three
  registered actors.
- Targeted ESLint: no errors.
- No live xAI call occurred and no thread mode changed.

The implementation, prompt, test evidence, and exact operational boundary are
recorded in the attached artifact. The first live call remains the pilot, not
this construction slice. Observed local-control execution advances `executed=`
from 103 to 104.
