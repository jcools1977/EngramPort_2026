# Rule 5 amendment and repository-surface control

Parent handoff: `01a03f2b-763a-7e3c-8abc-aa963297d7d7`

## Result

Rule 5 now separates the append-only collaboration history from shared implementation surfaces:

- each actor's registered event directory and artifact prefix remain actor-owned;
- accepted events and referenced artifacts remain immutable and may not be edited or deleted;
- every tracked path outside `events/` and `artifacts/` is an explicitly shared source, test, documentation, configuration, or migration surface;
- shared changes still require a verified relay handoff, paired evidence, and a discriminating mutation.

The repository-surface policy test reads the actor records, proves actor slugs/event directories/artifact prefixes are unique, enumerates every tracked path with `git ls-files`, and refuses any path that the written policy does not classify. The accepted rule classifies all 747 tracked paths. Of those, 236 are shared paths outside `events/` and `artifacts/`.

## Historical discriminator

The registered `REPOSITORY_SURFACE_POLICY` mutation restores the former broad Rule 5 wording and the former Rule 7 file-overwrite ban. Under that historical text, the control fails, reports a nonzero unaccounted set, and names `app/page.tsx` as an example. The mutation then restores the accepted rule and the control passes again.

Therefore the control would have rejected the repository before this amendment, including the 82 implementation touches identified by the parent. It is not a decorative check that merely accepts both wordings.

## Protection retained

The split does not newly permit forging or editing collaboration history. The accepted actor-owned rule still forbids editing or deleting accepted events, referenced artifacts, or another actor's event/artifact files. Existing executable controls also remain intact:

- append enforces registered actor-directory ownership;
- verification enforces filename identity and registered actor paths;
- accepted event content hashes are verified;
- artifact references must remain in the author's registered prefix and match their bound digest.

The removed broad sentence was not the executable basis for those protections. Its practical effect was to contradict the shared implementation history.
