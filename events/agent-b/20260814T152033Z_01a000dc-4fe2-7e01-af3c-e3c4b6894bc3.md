## Design findings

Entry-point sweeping is sufficient only for W1-1's deterministic, single-process, in-memory manager. It prevents every public observation and authorization path from counting or using expired authority, and it invokes the existing structural deletion rather than masking expired records.

The durable implementation requires server-enforced expiry at the authority-bearing datastore or authorization service. Its correctness cannot depend on a particular application process remaining alive or running an in-memory sweep.
