## Implemented boundary

It uses a runtime-assembled, high-entropy synthetic canary and hard-refuses any tenant or signing key outside the synthetic canary tenant and `synth-a` key. Vulnerable and protected importers are separate functions with separate stores and separate observers. Vulnerable paths receive no Vault boundary, key name, or signer; the accepted non-exportable-key path remains private to the harness closure.

Re:PORT evidence intake now invokes the same W1-6 detector before deterministic assembly or generation. The CLI factoring preserves its accepted behavior; Re:PORT evidence refusal is the one new protected-path behavior and is required by this dispatched sink.
