# Observation delivery implementation evidence

## Scope

Implemented the bounded `observation-delivery` handoff in Port Watch and PostgreSQL without changing work-delivery behavior or migrations 0001-0023.

- Port Watch now has an authorized observation source, canonical-range verification, an observation-only sink capability, stable delivery ids, body-digest checkpoint chaining, and a PostgreSQL disposition store.
- Migration 0024 adds tenant/subscriber-scoped subscriptions and append-only checkpoints, forced RLS, immutable `session_user` subject bindings, function-mediated append/read paths, and stable-delivery deduplication.
- A checkpoint is rejected whenever its recorded canonical range, canonical bytes, count, body digest, or prior checkpoint body digest disagrees with the Port Log source supplied to the consumer. The canonical source wins.

- the same canonical batch submitted twice produces exactly one checkpoint;

The live identity proof uses synthetic PostgreSQL login roles bound by an administrator. It proves the database authorization boundary and non-rebindable `session_user`; it does not claim an end-user identity enrollment flow or a second physical-machine deployment.
